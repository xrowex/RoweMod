# RoweMod 3.3.6

Custom emotes now download automatically when you open the Emotes page.

- Downloads the official emote animation bundle on first use, verifies its SHA-256, and saves it in `Mods/RoweMod/Bundles`.
- Reuses a verified installed pack without downloading it again.
- Loads the downloaded animations into the emote and dance lists without restarting the game. If an emote is already playing, the list refresh waits for it to finish.
- Shows download status and supports retry through Refresh Emotes. Failed downloads leave the existing file intact and clean up temporary files.
- Keeps the four-button pie menu: RoweMod up, Replay right, Emotes down, Vehicle Tuning left.

## Install

Update the mod DLL to 3.3.6, restart BMX Streets, load a map, and open Emotes. An internet connection is needed for the first download; the installed pack works offline afterward. No ZIP installation is required.

The optional `RoweMod-Emotes-3.3.5.zip` attached to this release contains the same pack for manual/offline installation. Extract it into the BMX Streets game folder, merging `Mods`.

## Testing and limitations

The Release build, 98 existing automated checks, 16 focused download/cache checks, and compiled native-hook audit passed. The new checks cover first download, cache reuse, corrupt downloads, connection failures, retry, catalog registration, and staging failures with stubbed Unity/network services. Bundle checksum and archive layout were also verified. Automatic in-game download, list refresh, and playback still need a fresh game test. Imported emotes remain local; this does not add multiplayer emote synchronization. The TV and multiplayer-media limitations documented in 3.3.5 still apply.
