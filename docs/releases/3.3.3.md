# RoweMod 3.3.3

Cleaner trick tools, complete rider-and-bike animation packages, and recovery fixes for Replay, manual IK, sparks, grinds, and hosting.

## What's new for players

- **Cleaner Trick Mapping:** the compact navigation, search, set groups, and trick rows now share one consistent layout.
- **Complete trick previews:** previews wait for the current trick to finish before repeating and restore the rider when stopped or closed.
- **One-click custom animations:** complete Studio packages apply coordinated rider and bike clips, timing, and mirrored-direction behavior to the selected trick.
- **Reliable manual poses:** custom foot and hip positions use the game's tracked manual state, so ordinary hop landings do not trigger them. Real and fakie manuals keep their pose through brief contact gaps.
- **Replay recovery:** normal Back remains unchanged. If Replay gets stuck, hold B or Escape for two seconds to request a safe exit through the game's own Replay systems.
- **Peg sparks:** native peg contact drives sliding sparks, optional entry bursts, metal impact audio, and recorded Replay samples.
- **Faster Grind Poses:** controls are grouped into Bike, Rider, Balance, and Transform sections, and preset discovery is cached.
- **Host-session fix:** starting a session no longer throws from the player-capacity nullable conversion.

## Animation Studio

The repository now includes the paired rider-and-bike authoring workspace, package format, validation scripts, and creator documentation. Runtime packages isolate the selected trick's animation tracks so applying or resetting one package does not alter unrelated tricks.

## Before updating

Close BMX Streets, back up your current DLL and settings, and replace `Mods/rowemod.dll` with the attached file. No configuration reset is required.
