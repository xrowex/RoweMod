# RoweMod 3.3.17

Restores compatibility with the October 23 Streets update: Steam build
**26175718**, game version **2.0.0.3072.0**.

That update moved native functions. RoweMod 3.3.16 safely skipped its seven
native hook groups, including outfit-completion handling. Custom material
bundles could load while their outfit requests timed out, leaving clothes white.

The new profile restores those hooks, custom-hair visibility, and the other
guarded native groups. All four older build profiles and address safety checks
are retained.

## Install

Close Streets, replace the installed RoweMod DLL with 3.3.17, then restart.
The normal in-mod updater also provides this release. Existing clothing files,
textures, presets, and settings are retained; this fix needs no clothing-pack
reinstall or preset reset.

## Verification

Release build and **466 automated checks** passed. All **17** native targets
were checked for unique ownership across **201,337 methods in 162 assemblies**.
All **1,687** compiled game-wrapper references resolve against three tested
interop versions, and all **16** native patch signatures match the new wrappers.

Fresh runtime checks restored **7/7** native feature groups and both trick
guards. Repeated local outfit-preset loads and a real map load completed custom
equips and applied their selected materials without equip timeouts.

The reporting player's exact clothing bundles, physical controller behavior,
and multiplayer appearance remain unverified. Replay props retain 3.3.16's
current-session scope; saved replay-file persistence is unchanged.
