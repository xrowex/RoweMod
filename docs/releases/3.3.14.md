# RoweMod 3.3.14

Fixes custom clothing materials left white or lost when entering gameplay, and
supports BMX Streets build **26150520** / **2.0.0.3070.0**.

- Added an audited native-hook profile for the October 22 Streets binary. The
  new profile restores equip-completion handling used by custom materials and
  preserves all three previously supported builds and native safety checks.
- A selected material now covers every renderer and material slot within the
  equipped clothing item, including inactive children. Previously the first
  renderer could receive the texture while the visible clothing stayed white.
- Gameplay restores the current model/material choices even with no named
  clothing preset. It also resolves the equip-slot owner from the spawn child.
- Overlapping spawn, gameplay-enter, and replay-exit requests coalesce. Stale
  requests stop when the rider changes or a newer selection/reset takes over.
- Eyewear material choices now persist with the current outfit.

## Install

Close Streets, replace `BMX Streets/Mods/rowemod.dll` with 3.3.14, then restart.
The in-mod updater also provides this release. Existing selections are retained.
