# RoweMod 3.3.4

This hotfix restores visible peg sparks.

## Fixed

- Spark particles no longer disappear because HDRP culls the moved AssetBundle VFX rig.
- Spark color now uses the intended hot-orange graph properties.
- VFX startup explicitly sends the graph's authored play event for reliable IL2CPP activation.

## Before updating

Close BMX Streets, back up your current DLL and settings, and replace `Mods/rowemod.dll` with the attached file. No configuration reset is required.

## Testing status

The Release build and project checks passed. A live game test first confirmed that particles were spawning but reported `culled=True`; after the fix, the same test build produced visible sparks during gameplay. Native peg-contact grinding and the final MelonLoader log were checked as well.
