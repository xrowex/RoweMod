# RoweMod 3.3.11

Restores compatibility with the October 21 BMX Streets update (Steam build 26117410).
The update moved the native methods used by RoweMod, causing the mod to skip its
native hooks and outfit materials to time out waiting for equip completion.

- Restores the hooks used by material application, custom-hair visibility,
  Disable Trick Tweaking, and nose-manual/hang-five controls.
- Updates all 17 audited targets, including manual IK, grind remapping, landing
  assistance, drone placement, host limits, player labels, and challenge hooks.
- Preserves both earlier supported game builds and continues to reject unknown
  binaries and shared native functions.
- Adds a visible **Trick Speed (x)** slider (0.05x to 10x) and **Reset to 1x** in
  Tricks → select a trick. It uses the existing saved per-trick speed setting.

## Install

Close Streets, replace `BMX Streets/Mods/rowemod.dll` with 3.3.11, then restart.
The in-mod updater also provides this release. Existing customization files and
presets remain supported.

## Verification

The Release build and 235 automated checks passed. The fresh native metadata
audit checked 201,418 methods across 162 assemblies and confirmed one owner for
each of the 17 approved targets. The unsafe shared getter has 500 aliases and
remains rejected. See `docs/native-hook-audit-20261022.json`.

All 1,645 compiled wrapper member references resolve against both the preceding
and current interop, and all 16 compiled patch signatures match both wrapper sets.

Fresh runtime logs confirm 7/7 native feature groups and both tweak/nose-manual
guards. Bust, hat, and hair each completed native equipping and received their
materials without timeouts; hair settled active and enabled with hiding disabled.
These checks establish startup and outfit completion. Riding/controller behavior,
per-trick speed behavior, and multiplayer still require gameplay acceptance.
