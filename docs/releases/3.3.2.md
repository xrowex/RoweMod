# RoweMod 3.3.2

More rider customization, new replay lens details, and safer loading.

## What's new for players

- **Tweak control:** reworked Disable Trick Tweaking for manual and automatic bike tweaks.
- **Hang 5 controls:** keep normal game behavior, disable nose-manual variants, or swap the bumper-selected sides.
- **Custom manual poses:** move and rotate each foot and the hips separately. The in-game handles are bigger, the controls are clearer, and adjustment ranges are wider.
- **Custom rider animations:** load animation clips from a Unity bundle and choose which trick phase they replace. You need to supply the custom clips separately.
- **Physics update rate:** optional 30-250 Hz control. The default remains whatever the game uses. Higher settings cost more CPU; they do not increase FPS.
- **VX1000 replay look:** adjustable film grain, lens dirt, and fine scratches.
- **Menu and tuning cleanup:** improved landing-assist controls, One Point Oh toggles, and grind-pose scrolling.
- **Safer startup:** replaced early startup patches and guarded against unsupported game builds, including the cause of the earlier tweak-related map-spawn failure.
- **Rear pegs:** removed RoweMod's custom-frame peg workaround because the placement issue is in the base game.

## Where to find it

- **Ride > Handling:** Disable Trick Tweaking, Nose Manual Variants (Hang 5), and the physics update rate.
- **Customize > Stance & Look:** manual and nose-manual foot/hip pose controls.
- **Trick animation editor:** custom rider clips.
- **Replay Camera Lab:** VX1000 lens character controls.

## Before updating

Close BMX Streets, back up your current DLL and settings, and replace `Mods/rowemod.dll` with the attached file. Restart the game. No config reset is required.

**Testing status:** the build and 73 automated logic checks passed, and native hook targets/signatures were audited. The newest nose-manual, pose-editor, and startup changes still need broader in-game testing. Please report issues with the latest MelonLoader log; this release is not a claim that every feature has been play-tested.
