# RoweMod 3.3.8

Custom characters and hair now restore correctly on the main-menu preview without requiring a named preset.

- Finds the menu character even when its spawn event was missed or no preset is saved.
- Restores your current custom models and materials to the menu preview. Saved presets remain available as a fallback.
- Includes the automatic custom-hair fix for hats and busts from 3.3.7; no new toggle is required.
- Keeps automatic menu restoration separate from gameplay characters, and preserves manual selections or Restore Game Outfit actions made while the menu loads.
- Uses a delay that works while paused, avoids duplicate restores, and cancels outdated work when the preview character or scene changes.

## Install

Update `BMX Streets/Mods/rowemod.dll` to 3.3.8 while the game is closed, then restart. Existing customization files, presets, and automatic emote downloads remain supported.

The optional `RoweMod-Emotes-3.3.5.zip` contains the unchanged emote pack for manual/offline installation. Extract it into the BMX Streets game folder, merging `Mods`. It is not required for this update.

## Verification

Main-menu runtime logs confirmed that dreads, hat, and bust were restored. The delayed hair check reported the hair active, its renderer enabled, rendering not forced off, and the hide flag cleared after clothing finished equipping. The Release build, automated tests, and native-hook audits passed. This update does not add multiplayer synchronization or change the existing experimental TV/media limitations.
