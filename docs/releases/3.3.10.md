# RoweMod 3.3.10

Restores native-hook support for BMX Streets build 26071101, following the startup-only fix in 3.3.9.

- Adds a game-hash-specific profile for all 17 native targets while retaining the original audited build.
- Updates the renamed native equip coroutine used by custom-hair visibility and asynchronous material application.
- Captures native request identity before source cloning, waits for an existing game outfit load to finish, and cancels queued work when a newer selection replaces it.
- Supports the updated drone firing signatures.
- Restores the native hooks used by host limits, player labels, manual IK, grind remapping, landing assistance, drone placement, tweak and nose-manual controls, and challenge lifecycle/trick capture.
- Keeps native-address and detour-backend validation, group rollback, and rejection of unknown binaries and shared native getters.

## Install

Replace `BMX Streets/Mods/rowemod.dll` with 3.3.10 while the game is closed, then restart. Existing customization files, presets, and emote downloads remain supported.

## Verification

The native metadata audit checked all 199,854 methods across 162 assemblies and confirmed unique ownership and exact signatures for all 17 approved targets. The rejected shared getter still has 499 aliases. See `docs/native-hook-audit-20261020.json` for the updated addresses and signatures.

The Release build and 220 automated checks passed. All 1,645 compiled wrapper member references resolve against both the original and updated interop assemblies; both compiled hook/signature audits pass as well.

Fresh runtime logs confirm 7/7 native feature groups and both tweak/nose-manual guards. Bust, hat, and hair each completed native equipping and received their materials without timeouts; the settled hair renderer remained active, enabled, and visible to rendering. These are native runtime and rendering-state checks. Controller-driven behavior for every affected feature, visible gameplay acceptance, and multiplayer still require an in-game pass; automated game-window access was unavailable for that pass.
