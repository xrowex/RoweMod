# RoweMod 3.3.13

Preserves trick preset mappings through incomplete runtime catalogs and adds
optional controls for manual activation delay and stick sensitivity.

- Trick preset saves retain LT/RT sets, unloaded sets, extra slots, and mappings
  whose trick assets are temporarily unavailable. Known set-name aliases restore
  to their matching native set; ambiguous names are left alone.
- Missing or unnamed trick entries no longer erase a usable live slot. An
  explicitly disabled entry remains disabled.
- Preset refresh uses the local rider's native trick provider and refresh method.
  It no longer enables disabled components or broadcasts initialization calls.
- **Ride → Handling → Manual Activation** offers separate Manual and Nose Manual
  delays in milliseconds and minimum stick thresholds. Choose **Customize Manual
  Activation** to start from the current game values. **Use Game Activation**
  restores the captured values. The override defaults off and saves with Physics
  Presets. Zero delay activates on the next eligible native physics tick.

## Install

Close Streets, replace `BMX Streets/Mods/rowemod.dll` with 3.3.13, then restart.
The in-mod updater also provides this release.
