# RoweMod 3.3.7

Custom hair now stays visible when using hats and busts on custom characters.

- Stops clothing hide flags from removing custom hair, including after changing your hat or bust. This is automatic; there is no new toggle.
- Fixes physics-hair equip timeouts by detecting when the game's equip coroutine actually finishes.
- Applies hair materials after equipping, includes hidden hair meshes, and cancels old material requests when you switch selections.
- Keeps the existing Hair show/hide control and Restore Game Outfit behavior. The fix is limited to local custom hair and does not change other players' outfits or other clothing hide flags.

## Install

Replace `BMX Streets/Mods/rowemod.dll` with the 3.3.7 DLL while the game is closed, then restart. Existing hair bundles, presets, and the automatic emote download from 3.3.6 remain supported.

The optional `RoweMod-Emotes-3.3.5.zip` contains the unchanged emote pack for manual/offline installation. Extract it into the BMX Streets game folder, merging `Mods`; it is not needed for this hair fix.

## Testing and limitations

The revised custom-hair fix was confirmed working in game by the user. The Release build, automated checks, compiled hook signatures, and native-address uniqueness audit passed. This is a focused character-customization fix, not a new multiplayer synchronization feature. Existing experimental TV and multiplayer-media limitations are unchanged.
