# RoweMod 3.3.12

Restores Grind Friction and aligns new physics configs with Streets' current
Gravity and Small Hop controls. Previously RoweMod displayed raw physics values
and replaced base hop velocities with 4.2, while Streets uses a separate quick-hop
multiplier whose default is 1x.

- **Ride → Handling → Grinding**: restored Custom Grind Friction with the previous
  0–5 range and 0.03 reset value. It uses copies assigned only to local peg
  colliders and restores native materials when disabled. It defaults off.
- New configs use Streets' native Gravity and Small Hop values, ranges, and Reset
  values. They preserve current Streets preferences and leave base hop velocities
  and world gravity untouched.
- Existing configs and older Physics Presets retain their raw values in **Legacy
  raw tune** mode. Mount the local bike, open **Ride → Handling**, and choose
  **Use Streets Physics Values** to restore the original base values and switch
  to current Streets settings. Reset on Small Hop then selects the native 1x default.
- Native Physics Presets capture and restore the current game values. Loading a
  preset retains the active vehicle selection; older friction presets preserve
  deliberate zero-friction settings.
- Later changes through Streets' native controls are preserved instead of
  repeatedly overwritten. Unbound prefabs and remote proxies are not edited.

## Install

Close Streets, replace `BMX Streets/Mods/rowemod.dll` with 3.3.12, then restart.
The in-mod updater also provides this release. Existing tunes remain in Legacy
mode until you explicitly switch or reset Handling.
